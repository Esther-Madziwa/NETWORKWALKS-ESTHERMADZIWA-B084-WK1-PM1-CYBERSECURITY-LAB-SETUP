
# Advanced SOC Wireshark Challenge Labs (Extra)

I successfully completed the 6 advanced SOC investigative labs provided by Network Walks to sharpen my network security monitoring and deep packet analysis skills.

##  Skills and Tasks Mastered

### 1. Identify the Attacker's IP (SOC Lab 3)
* **Objective:** Isolate malicious network traffic actors.
* **Key Takeaway:** Analyzed packet patterns to determine source threat addresses.

### 2. Follow TCP Stream 1 (SOC Lab 4)
* **Objective:** Reconstruct conversation payloads.
* **Key Takeaway:** Used Wireshark's stream reassembly to read raw data exchanged across sessions.

### 3. Hidden Data (SOC Lab 5)
* **Objective:** Uncover obscured variables.
* **Key Takeaway:** Audited protocol fields to track down stealthy parameter parameters hidden within standard requests.

### 4. Clear Text Passwords (SOC Lab 6)
* **Objective:** Detect unencrypted configurations.
* **Key Takeaway:** Located plain-text credentials and vulnerable transmission vectors traversing the wire.

### 5. Brute Force (SOC Lab 7)
* **Objective:** Pinpoint automated attack trends.
* **Key Takeaway:** Diagnosed systematic credential-stuffing patterns and high-frequency authorization attempts.

### 6. VoIP Calls (SOC Lab 8)
* **Objective:** Analyze and replay session media.
* **Key Takeaway:** Examined SIP signaling mechanics (INVITE/Ringing/200 OK) and extracted payload voice traffic streams using RTP playbacks.
